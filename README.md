# LiveRoad

## 1. Cài môi trường

- Windows + PowerShell
- Git
- Docker Desktop
- Node.js >= 22.13
- Python 3.11 hoặc 3.12

## 2. Chạy luồng IoT

Mở PowerShell tại thư mục project:

```powershell
.\scripts\start-iot.ps1
```

Mở:

```text
http://localhost:8101
```

## 3. Chạy luồng video

Mở terminal PowerShell thứ hai:

```powershell
.\scripts\start-video.ps1
```

Mở:

```text
http://localhost:3000
```

Sau đó tải video lên trên website.
